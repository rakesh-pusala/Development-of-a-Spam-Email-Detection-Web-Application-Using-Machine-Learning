# Development-of-a-Spam-Email-Detection-Web-Application-Using-Machine-Learning
Spam emails remain a major challenge in digital communication due to their role in phishing, malware distribution, and financial fraud 📧. Traditional rule-based filtering methods using techniques like Bag-of-Words and TF-IDF often fail to capture contextual relationships in text. This project proposes a hybrid spam detection framework combining DistilBERT contextual embeddings with ten supervised machine learning classifiers. Using the Email Spam Collection Dataset, preprocessing steps such as normalization, tokenization, stopword removal, and stemming were applied. The DistilBERT-based embeddings improved semantic representation and classification performance. Among the tested models, the Multi-Layer Perceptron achieved the highest accuracy of 98.03%. A Flask web application was also developed to enable real-time spam prediction, demonstrating the practical effectiveness of transformer-based hybrid spam detection systems.
